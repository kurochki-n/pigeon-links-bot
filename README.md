# Pigeon Links Bot

Система из двух типов Telegram-ботов для выдачи материалов за подписку на канал:

- **основной бот** — личный кабинет, где пользователь подключает канал, создаёт ссылки, публикует посты и смотрит статистику;
- **бот для подписчиков** — отдельный бот пользователя, который проверяет подписку и выдаёт материалы людям.

Проект рассчитан на владельцев каналов, маркетологов и авторов. Один основной бот может обслуживать несколько независимых пользователей: у каждого свой бот для подписчиков, канал, ссылки и статистика.

## Возможности

- Создание «умных» ссылок для рекламы, постов, партнёров и лид-магнитов.
- Проверка подписки на Telegram-канал перед выдачей материала.
- Выдача текста, фото, видео, документа, GIF-анимации или только вашего сообщения.
- Выдача свежего ZIP-архива публичного GitHub-репозитория по отдельной кнопке.
- Отдельные ссылки для источников трафика: например, `Реклама`, `Блогер Анна` или `Сайт`.
- Статистика по всем ссылкам и каждому источнику: переходы, уникальные пользователи, подписки и конверсия.
- Автономный HTML-отчёт, который можно открыть на компьютере без сайта и переслать коллегам.
- Публикация постов в подключённый канал: текст или медиа и URL-кнопки.

## Как это видит подписчик

1. Человек открывает вашу специальную ссылку в Telegram.
2. Если он уже подписан на канал, бот сразу отправляет материал.
3. Если не подписан, бот предлагает кнопку **«Подписаться на канал»**.
4. После вступления человек нажимает **«Проверить подписку»** и получает материал.

Повторные открытия одной ссылки учитываются как переходы, но один аккаунт считается только один раз в показателе уникальных пользователей.

# Установка и первый запуск

Ниже описан запуск на своём компьютере. Выполняйте пункты по порядку. Для постоянной работы бот должен быть запущен круглосуточно — в конце есть пояснение, как это организовать.

## Что понадобится

- аккаунт Telegram;
- Telegram-канал, на который вы хотите собирать подписчиков;
- компьютер с Windows, macOS или Linux;
- интернет;
- установленный Python версии 3.12;
- установленный `uv` — программа, которая подготовит всё необходимое для запуска.

## 1. Создайте основной бот настроек и получите токен

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте ему команду `/newbot`.
3. Укажите имя, которое будут видеть люди. Например: `Материалы компании`.
4. Придумайте username. Он обязательно должен заканчиваться на `bot`, например `company_materials_bot`.
5. BotFather пришлёт строку, похожую на эту:

   ```text
   123456789:AAExampleVerySecretToken
   ```

   Это токен — пароль от вашего бота. Сохраните его, но никому не отправляйте и не публикуйте.

> Если токен попал к постороннему, в BotFather откройте настройки бота и перевыпустите **API Token**. Старый токен после этого перестанет работать.

## 2. Скачайте проект

Если вы получили проект архивом, распакуйте его в удобную папку, например в «Документы».

Если проект размещён на GitHub и у вас есть ссылка на него:

1. Откройте страницу проекта.
2. Нажмите зелёную кнопку **Code** → **Download ZIP**.
3. Распакуйте скачанный архив.

Дальше все команды нужно вводить именно в папке проекта — там, где находятся файлы `README.md` и `pyproject.toml`.

### Как открыть терминал в папке проекта

- **Windows:** откройте папку в Проводнике, щёлкните правой кнопкой мыши по пустому месту и выберите «Открыть в Терминале» или «Открыть окно PowerShell здесь».
- **macOS:** откройте программу «Терминал», введите `cd ` (с пробелом), перетащите папку проекта в окно Терминала и нажмите Enter.
- **Linux:** откройте папку в файловом менеджере и выберите «Открыть в терминале».

## 3. Установите uv и Python

Откройте [официальную инструкцию по установке uv](https://docs.astral.sh/uv/getting-started/installation/) и выполните команду для своей операционной системы.

Закройте и снова откройте терминал. Затем проверьте установку:

```bash
uv --version
```

Если появилась версия `uv`, всё в порядке. Теперь установите Python нужной версии:

```bash
uv python install 3.12
```

## 4. Подготовьте программу

В терминале, находясь в папке проекта, выполните:

```bash
uv sync
```

При первом запуске команда скачает нужные компоненты и создаст служебную папку `.venv`. Это нормально и может занять несколько минут. В дальнейшем повторять её нужно только после обновления проекта.

## 5. Создайте файл настроек

В проекте есть пример настроек `.env.example`. Сделайте его копию с именем `.env`.

**Windows PowerShell:**

```powershell
Copy-Item .env.example .env
```

**macOS, Linux или Git Bash:**

```bash
cp .env.example .env
```

Откройте созданный файл `.env` в обычном текстовом редакторе. Замените текст после `BOT_TOKEN=` на токен из BotFather:

```env
BOT_TOKEN=123456789:AAExampleVerySecretToken
DATABASE_URL=sqlite+aiosqlite:///./data/database.db
STORAGE_PATH=./data/storage
DELIVERY_TOKEN_KEY_PATH=./data/delivery_tokens.key
LOG_LEVEL=INFO
MAX_TELEGRAM_FILE_SIZE=20971520
```

Для первого запуска меняйте только `BOT_TOKEN`.

Остальные строки означают:

- `DATABASE_URL` — где хранится статистика и настройки;
- `STORAGE_PATH` — папка с загруженными материалами;
- `DELIVERY_TOKEN_KEY_PATH` — файл с ключом для шифрования токенов пользовательских ботов;
- `LOG_LEVEL` — подробность сообщений в терминале;
- `MAX_TELEGRAM_FILE_SIZE` — максимальный размер одного загружаемого материала и ZIP-архива GitHub в байтах. По умолчанию это 20 МБ;

> Файл `.env` содержит секретный токен. Не отправляйте его другим людям и не загружайте в GitHub.

## 6. Запустите бота

В той же папке выполните:

```bash
uv run python -m bot.main
```

При первом запуске бот сам создаст папку `data`, базу данных и папку для материалов. Когда в терминале появится строка наподобие `Bot starting`, бот готов к работе.

Не закрывайте терминал: пока это окно открыто, бот работает. Чтобы безопасно остановить его, нажмите `Ctrl + C`.

Если команда сообщает, что `BOT_TOKEN` не задан, проверьте, что файл называется именно `.env`, находится рядом с `pyproject.toml` и в нём указан токен без кавычек и лишних пробелов.

# Настройка в Telegram

Откройте основной бот и нажмите **Start** или отправьте `/start`. Он покажет порядок настройки.

## 1. Подключите отдельного бота для подписчиков

1. В основном боте отправьте `/bot`.
2. Откройте [@BotFather](https://t.me/BotFather) и создайте ещё одного бота командой `/newbot`.
3. Скопируйте полученный токен.
4. Вернитесь в основной бот и пришлите токен одним сообщением.
5. Основной бот проверит токен, удалит сообщение с ним и сохранит токен в зашифрованном виде.
6. После сообщения об успешном подключении отдельный бот автоматически запускается. Отдельную программу для него запускать не нужно.

Не используйте токен основного бота. Для подписчиков обязательно нужен второй бот.

## 2. Подключите канал

1. В основном боте отправьте `/channel`.
2. Нажмите **«Продолжить подключение канала»**. Откроется бот для подписчиков.
3. Добавьте именно бота для подписчиков в канал как администратора.
4. Разрешите ему публиковать сообщения. Для закрытого канала также разрешите создавать пригласительные ссылки.
5. В чате с ботом для подписчиков нажмите **«Выбрать канал»** и выберите нужный канал.
6. После подтверждения вернитесь в основной бот.

Ссылка подключения действует 15 минут и работает только для аккаунта, который запросил её в основном боте.

## 3. Создайте первую ссылку

1. Отправьте основному боту `/add`.
2. Напишите внутреннее название ссылки. Его видите только вы, например `Реклама у блогера`.
3. Пришлите готовый материал для подписчика: текст, фото, видео, GIF или документ. Можно прислать несколько сообщений и файлов в нужном порядке; подпись к фото или видео тоже сохранится.
4. Нажмите **«Готово — перейти к ссылкам»**.
5. Пришлите ссылки для кнопок. Ссылка на публичный GitHub-репозиторий создаст кнопку скачивания свежего ZIP-архива; любая другая ссылка станет обычной кнопкой. Можно добавить сколько угодно ссылок.
6. Нажмите **«Готово — посмотреть»**, проверьте предпросмотр и выберите **«Сохранить и получить ссылку»**.
7. Скопируйте созданную ссылку и разместите её в рекламе, посте, письме или QR-коде.

### Как правильно проверить ссылку

Проверяйте её с аккаунта, который ещё не подписан на канал, или попросите коллегу:

1. Откройте ссылку.
2. Нажмите **«Подписаться на канал»**.
3. Вернитесь в бот и нажмите **«Проверить подписку»**.
4. Убедитесь, что материал пришёл.

# Работа с ботом

## Ссылки и источники трафика

Команда `/links` открывает список активных ссылок. В карточке можно открыть ссылку, посмотреть статистику, создать источники трафика или отключить ссылку.

Чтобы понять, откуда пришёл человек, откройте нужную ссылку → **«Источники»** → **«Добавить источник»**. Назовите его, например `YouTube` или `Партнёр Иван`, и используйте выданную отдельную ссылку.

Не добавляйте к ссылке вручную UTM-метки: Telegram не передаёт их боту. Для раздельной статистики используйте источники внутри бота.

Отключённая ссылка перестаёт выдавать материал, но её статистика сохраняется.

## Статистика и отчёт

Отправьте `/stats`, чтобы увидеть общую статистику или выбрать конкретную ссылку.

| Показатель | Что он значит |
|---|---|
| Переходы | Все открытия ссылки, включая повторные. |
| Уникальные пользователи | Количество разных Telegram-аккаунтов, открывших ссылку. |
| Уже были подписаны | Люди, подписанные на канал при первом переходе. |
| Подписались после перехода | Люди, которые подписались и затем нажали «Проверить подписку». |
| Конверсия | Доля подписавшихся среди тех, кто не был подписан при первом переходе. |

Кнопка **«Скачать понятный отчёт»** отправит HTML-файл. Скачайте его из Telegram и откройте двойным щелчком в браузере. Отчёт работает без сайта и без подключения к интернету.

## Публикация в канал

Команда `/post` помогает сделать пост от имени подключённого канала.

1. Отправьте основному боту `/post`.
2. Пришлите готовый пост: текст, фото, видео, документ или GIF. Можно прислать несколько сообщений и файлов в нужном порядке.
3. Нажмите **«Готово — добавить кнопки»**.
4. При необходимости добавьте URL-кнопки. Их число ограничено только техническим пределом Telegram — 100 кнопок.
5. Нажмите **«Посмотреть перед публикацией»**, проверьте весь пост и выберите **«Да, опубликовать в канал»**.

Публикация не попадёт в канал без последнего подтверждения.

## Команды

| Команда | Действие |
|---|---|
| `/start` | Открыть личный кабинет. |
| `/bot` | Подключить или заменить отдельного бота для подписчиков. |
| `/channel` | Подключить, проверить, заменить или удалить канал. |
| `/add` | Создать умную ссылку. |
| `/links` | Управлять созданными ссылками и источниками. |
| `/post` | Подготовить и опубликовать пост в канале. |
| `/stats` | Посмотреть статистику и скачать отчёт. |
| `/cancel` | Отменить незаконченное действие. |

# Хранение данных, обновление и постоянная работа

## Что нужно сохранять

В папке `data` находятся база данных, материалы и файл `delivery_tokens.key`, которым зашифрованы токены ботов для подписчиков. Регулярно копируйте **всю папку `data`** в безопасное место.

Не теряйте `data/delivery_tokens.key`: без него после переноса или восстановления сервер не сможет запустить подключённых ботов. Никому не отправляйте этот файл.

## Как обновить проект

После получения новой версии проекта:

1. Сначала сделайте резервную копию папки `data`.
2. Замените файлы проекта новыми, но не заменяйте свой `.env` и папку `data`.
3. В терминале выполните:

   ```bash
   uv sync
   ```

4. Перезапустите бота командой:

   ```bash
   uv run python -m bot.main
   ```

## Как держать бота онлайн 24/7

Компьютер подходит для настройки и тестов. Если он выключится, уснёт или вы закроете терминал, бот перестанет отвечать.

Для постоянной работы перенесите проект на VPS или облачный сервис, где можно непрерывно запустить Python-программу. На сервере повторите шаги установки: скачайте проект, создайте `.env`, выполните `uv sync` и запустите `uv run python -m bot.main`. Обязательно настройте автоматический перезапуск процесса средствами выбранного сервера или облачного сервиса.

# Решение проблем

## Основной бот не отвечает

- Убедитесь, что команда запуска всё ещё работает в терминале.
- Проверьте токен в `.env`: без кавычек, пробелов и переноса на другую строку.
- Проверьте интернет и убедитесь, что токен не был перевыпущен в BotFather.

## Бот для подписчиков не отвечает

- В основном боте отправьте `/bot` и подключите его токен заново.
- Убедитесь в BotFather, что токен этого бота не был отозван.
- После замены бота заново подключите канал через `/channel` и замените старые опубликованные ссылки.

## Бот не может проверить подписку или опубликовать пост

Добавьте именно бота для подписчиков в нужный канал администратором, выдайте право на публикацию и снова подключите канал через `/channel` в основном боте. Для закрытого канала также нужно разрешение на создание пригласительных ссылок.

## Пользователь подписался, но проверка не проходит

Пусть он подождёт несколько секунд и снова нажмёт **«Проверить подписку»**. Иногда Telegram обновляет статус с небольшой задержкой. Также проверьте через `/channel`, что подключён нужный канал.

## Не приходит GitHub-архив

Бот пытается получить текущую версию публичного репозитория. Если архив слишком большой, GitHub недоступен или Telegram не может отправить файл, попробуйте позже или откройте сам репозиторий по его ссылке.

## Нужна проверка кода

Для разработчиков доступна команда:

```bash
uv run ruff check bot main.py
```

## Ограничения

- У каждого пользователя один бот для подписчиков и один подключённый канал.
- Приложение должно быть запущено только в одном экземпляре: два процесса будут одновременно получать обновления одних и тех же ботов.
- Для умной ссылки и поста можно добавить несколько сообщений: текст, фото, видео, документы или GIF. Они будут отправлены по порядку.
- GitHub-репозитории должны быть публичными.
- В статистику подписки попадают только люди, которые после вступления нажали кнопку проверки.
